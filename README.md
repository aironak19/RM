# Ronak Mehta — portfolio (v2)

Static site, no build step. Drop the contents of this folder into the root of the `RM` GitHub Pages repo and push.

```
index.html                 Portfolio (static HTML/CSS/JS — no React/Babel download)
assets/ronak.jpg           Portrait
assets/og.jpg              Social preview image (1200×630)
artifacts/index.html       Northstar People Suite — launcher for all nine tools
artifacts/<tool>/index.html   One self-contained app per tool
artifacts/shared/          Shared design system (ns.css), runtime (ns.js) and dataset (ns-data.js)
artifacts/shots/           Card screenshots (WebP, 800 & 1600 wide)
```

Tools: performance-nexus, compintel-pro, leaders-field-guide, competency-portal,
retention-radar, pulse, people-ops-desk, workforce-planner, pipeline-ats.

`support.js` from the old version is no longer used and can be deleted from the repo.
All tool data is fictional (Northstar Labs); state is saved in the visitor's browser only.
